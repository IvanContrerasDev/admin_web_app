# Precisión de verificación F-016

El contrato inicial administrativo y proveedor cuentan1–128puntos de código Unicode (`[...password].length`), no unidades UTF-16. Verificar también atributos HTML maxLength heredados del formulario: maxLength128 de un input cuenta unidades UTF-16 y puede bloquear128caracteres no BMP aunque el schema sea correcto. Conservar secreto sin trim y política neutral de cuenta existente; no reemplazarlo por política nueva antes OTP. Esta precisión ya pertenece al criterio/plan Unicode; no agrega DTO ni política de contraseña.

Mantener las garantías de catálogo público corregidas por F-015 cuando nuevos servicios de auth públicos se separen del controller de sesión. Rutas /sites y privados continúan protegidos. No deshacer las pruebas de bootstrap401/cancelación.
